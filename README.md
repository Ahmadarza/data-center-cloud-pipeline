# Data Center & Cloud Pipeline

Data pipeline dan Business Intelligence dashboard untuk mengolah data berita terkait sektor Data Center & Cloud di Indonesia.

## Project Overview

Project ini bertujuan untuk mengumpulkan, mengolah, dan menganalisis data berita dari beberapa sumber publik untuk menghasilkan business insight terkait perkembangan industri Data Center & Cloud.

Data diproses melalui tahapan web scraping, cleaning & filtering, business insight extraction, penyimpanan ke PostgreSQL, dan visualisasi melalui dashboard.
